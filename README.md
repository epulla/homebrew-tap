# epulla/homebrew-tap

Homebrew casks for [Ziran](https://github.com/epulla/ziran) and [Snipzy](https://github.com/epulla/snipzy).

```sh
brew install --cask epulla/tap/ziran
brew install --cask epulla/tap/snipzy
```

The apps are ad-hoc signed and not notarized. On first launch, open them from System Settings → Privacy & Security → **Open Anyway**.

Casks are bumped automatically by each app's release workflow.
